# Archive

Архівні документи попереднього проєкту (RN/RNC, Pyronix Rowan Night), збережені виключно як reference для adopt-and-discard.

## Контент

- `LEGACY_RN_CONTRIBUTING.md` — попередній CONTRIBUTING.md з RN/RNC. Містить корисні формулювання production rules, multiplayer authority taxonomy, GAS discipline. Не canonical для GrimProtocol.
- `LEGACY_RN_STYLE.md` — попередній STYLE.md з RN/RNC. Містить базові naming rules і Blueprint discipline. Не canonical для GrimProtocol.

## Правила

- Не посилатися на ці файли з активних docs.
- Не використовувати як source of truth.
- Видалити після того, як усі корисні фрагменти витягнуто у GP-канонічні документи.

Canonical правила GrimProtocol — у `/CONTRIBUTING.md`, `/STYLE.md` та `/Docs/`.
